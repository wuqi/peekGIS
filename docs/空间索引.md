### 📦 GeoPackage (.gpkg)

使用 GDAL 的 `ogrinfo` 执行 SQL，调用驱动内置的 `CreateSpatialIndex` 函数：

```bash
ogrinfo -sql "SELECT CreateSpatialIndex('table_name', 'geom_column')" your_data.gpkg
```

将 `table_name` 和 `geom_column` 替换为实际的表名和几何列名即可。

### 📁 Shapefile (.shp)

GDAL 对 Shapefile 的支持是通过 `ogrinfo` 执行特定的 OGR SQL 语句：

```bash
ogrinfo streets.shp -sql "CREATE SPATIAL INDEX ON streets"
```

其中 `streets` 是图层名（通常与文件名一致），生成的索引文件为同名的 `.qix` 文件。

### 🐘 PostgreSQL / PostGIS

GDAL 的 PostgreSQL 驱动本身**不提供**一个单独的“创建空间索引”命令。标准做法是用 `ogrinfo` 对数据库执行 `CREATE INDEX` SQL：

```bash
ogrinfo PG:"dbname='your_db'" -sql "CREATE INDEX idx_name ON your_table USING GIST (geom_column)"
```

这是 PostgreSQL/PostGIS 层面的 GiST 索引，GDAL 只是作为 SQL 执行通道。

**总结**：`.gpkg` 用 `CreateSpatialIndex()` 函数补建；`.shp` 用 `CREATE SPATIAL INDEX ON` 语句；`.fgb` 必须 `ogr2ogr` 重写；PostGIS 用 `CREATE INDEX ... USING GIST`。
