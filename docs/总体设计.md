## 2. 技术栈与版本策略

- 语言：**C++20**
- 构建：**xmake**（manifest 式 `add_requires` 拉依赖，三平台统一）
- 图形：OpenGL 3.3 Core（桌面）/ OpenGL ES 3（如需），GLFW + glad
- UI：Dear ImGui **docking** 分支 + **FreeType**（加载内置 霞鹜新晰黑 字体，DPI 适配）
- 地理：GDAL（含 OGR、OpenFileGDB、PROJ）
- 配置：TOML（toml11），缓存 LRU 上限等
- 渲染分工：
  - **VBO 主层**：100 万线/面要素的底层绘制（快、省内存、任意缩放免重算）
  - thorvg **暂不入 MVP**（后续可选做选中/标注/图例点缀层）

## 3. 模块划分

### 3.1 App / UI（ImGui docking）
- 启用 `ImGuiConfigFlags_DockingEnable`，建立 DockSpace。
- 布局（类 VSCode，但极简）：
  - **左 Dock**：图层面板（LayerPanel）
  - **中 Dock**：地图视口（MapView，渲染到 FBO 纹理后用 `ImGui::Image` 显示）
  - **底 Dock / 状态栏**：坐标显示（StatusBar）
- 输入：地图平移/缩放事件由 MapView 捕获，转给 MapScene。

### 3.2 MapScene（视图与数据模型）
- 维护：当前显示 CRS、视图变换（中心坐标、缩放比例、可选旋转）、图层列表。
- 提供：screen↔world 坐标互转、当前可见范围（bbox）。
- 每个 Layer 记录：源路径、源 CRS、要素数、可见性、绘制样式（颜色/线宽/分类）。

### 3.3 DataSource / IO（GDAL）
- 矢量：OGR 打开数据源 → 读 extent（头信息，毫秒级）→ 迭代要素构建 VBO。
- 空间索引：首次打开为源建立空间索引（`.qix`/R-tree，秒级），供后续按需查询（若未来做视口裁剪）。
- 栅格：GDAL 打开，读取 RPC 元数据；像素数据走 mmap 分块（见 3.7）。

### 3.4 GeomCache（VBO 几何缓存）
- 将“OGR 读取后的几何”序列化为紧凑二进制 `.geomcache`。
- 存放于 `<exe目录>/cache/`；文件名含 `sourceId = sha1(路径 + mtime + size)`，header 内记录源签名用于失效校验。
- **关键**：缓存中存**源 CRS 坐标**（非显示 CRS），以支持动态重投影（见详细设计）。
- 重开：命中且签名一致 → mmap 直接上传 GPU，跳过 OGR。
- **LRU 淘汰**：缓存总大小受 TOML 配置的上限约束；超限时按最近使用淘汰最久未访问的 `.geomcache`（见 Config 模块）。

### 3.5 Reproject（PROJ 动态重投影）
- **默认显示 CRS**：首次打开用**数据自身 CRS**；数据无 CRS 则回退 **EPSG:4326**。
- 加载时：源 CRS → 显示 CRS，一次性投影到 VBO（PROJ 单遍，1M 点耗时极低）。
- **切换显示 CRS**：通过**界面（下拉/按钮）显式切换**显示 CRS，从缓存的源坐标重新投影到新显示 CRS（仍是单遍，无需重读 OGR）。
- 多源对齐：各图层各自投影到统一显示 CRS，自然对齐。

### 3.6 Render（渲染管线）
- 主层：GL VBO（线 `LINES` / 面 三角化）按视图矩阵绘制。
- 渲染目标：离屏 FBO 纹理 → ImGui `Image` 贴到地图 Dock（便于停靠/缩放/resize）。
- 坐标拾取：鼠标 → 屏幕 → 显示 CRS（逆视图矩阵）→ 可选逆投影到源 CRS。

### 3.7 Raster（栅格 mmap 分块）
- 中等尺度卫片：文件 mmap → 按视口所需区域分块解码 → 上传纹理 → 贴图。
- **RPC 精确位置**：读取 `RPC` 元数据（GDAL metadata domain），用 `GDALCreateRPCTransformer` 将像素坐标精确转换为地理坐标（再经 CRS 变换到显示 CRS），实现**精确角点定位与显示**；若实现成本高，允许先按 RPC 计算四角经纬度并据此做简化仿射放置（与动态重投影同思路）。
- 多线程：解码在 Worker 线程，主线程只合成纹理。

### 3.10 Config（TOML 配置 + LRU）
- 配置文件：`config.toml`（位于 `<exe目录>/` 或 `<exe目录>/cache/`）。
- 内容示例：
  ```toml
  [cache]
  dir = "cache"          # 相对 exe 目录
  max_size_mb = 512      # LRU 上限，可配置
  [display]
  default_crs = "auto"   # auto=用数据自身CRS, 否则写 EPSG 如 "4326"
  dpi_aware = true
  [font]
  file = "LXGW.ttf"      # 霞鹜新晰黑
  ```
- 提供**配置界面**（ImGui）编辑并保存上述项；LRU 淘汰依据 `max_size_mb` 执行。

### 3.8 Threading
- 轻量 Worker 线程池（`std::jthread` + 无锁任务队列）。
- 场景：缓存未命中时后台建 VBO / 解码栅格；前台先显示范围框/低精度，渐进填充。

### 3.9 Platform
- 窗口/GL 上下文：GLFW（三平台）。
- mmap 抽象：Windows `CreateFileMapping` / POSIX `mmap`，统一接口。
- 交叉编译：xmake toolchain 指向 aarch64-linux-gnu（麒麟）。

## 4. 数据流

### 4.1 打开矢量图层（首次，无缓存）
```
用户选择文件
 → OGR 打开，读 extent → MapScene 设为全幅
 → Worker：迭代要素 → 拍平顶点(源CRS) → 写 .geomcache
 → 主线程：PROJ 源CRS→显示CRS 投影 → 上传 VBO
 → 渲染全幅
```

### 4.2 打开矢量图层（命中缓存）
```
sourceId + 签名校验
 → mmap .geomcache → 上传 VBO（源CRS坐标）
 → PROJ 投影到显示CRS → 渲染
 （亚秒级，无 OGR 解析）
```

### 4.3 平移/缩放
```
仅更新 MapScene 视图矩阵
 → 重绘同一 VBO（GPU，免重读/免重建）
```

### 4.4 切换显示 CRS（动态重投影）
```
用户选择新显示 CRS
 → 从 .geomcache 的源坐标 重新 PROJ 投影 → 新 VBO
 → 各图层对齐到新 CRS
```

## 6. 跨平台与构建策略

- **统一构建系统**：xmake，`xmake.lua` 见详细设计。
- **本机/原生构建**：
  - Win64：`xmake f -p windows -a x64 && xmake`
  - Linux-x64：`xmake f -p linux -a x64 && xmake`
  - 麒麟 aarch64（在麒麟上原生）：`xmake`
- **交叉构建（在 x64 主机 → 麒麟）**：
  - `xmake f -p linux -a arm64 --toolchain=cross --sdk=/opt/aarch64-linux-gnu && xmake`
  - 具体 toolchain 路径按环境配置（详见详细设计）。
- **依赖来源**：xrepo 仓库（`add_requires`），版本在 `xmake.lua` 锁定。

## 7. 关键技术决策（与常见误区对照）

| 决策 | 理由 | 被否方案 |
|------|------|----------|
| 百万要素主层用 **VBO 直接绘制** | 一次建缓冲，任意缩放仅改矩阵；内存小、60fps | 用 thorvg 为每要素建 `Shape`（内存 GB 级、每帧重绘贵） |
| **不预建全局 LOD 金字塔** | 用户要“打开就看”，半小时预建不可接受 | 离线 bake 全缩放瓦片金字塔（慢、体积大） |
| 缓存存**源 CRS 坐标** + 默认用**数据自身 CRS**（无则 4326） | 支持运行时界面切换显示 CRS，重投影只需单遍数学，无需重读 OGR | 缓存存已投影坐标（切 CRS 需重建/重读） |
| 渲染到 **FBO 纹理 → ImGui::Image** | 地图可停靠/缩放/resize，与 UI 解耦 | 直接画到默认帧缓冲（难与 docking 布局协调） |
| 栅格走 **mmap 分块 + 多线程解码**；RPC **精确位置**（退化版可简化） | 中等尺度卫片流畅；RPC 角点精确定位 | 整图读入内存；仅展示 RPC 元数据 |
| 缓存置于 **`<exe>/cache`** + **TOML 配置 LRU 上限** | 便携、可控、依赖精简（不用 sqlite3） | 用 sqlite3 记录清单（偏重） |
| 字体 **霞鹜新晰黑** + **DPI 适配**（FreeType） | 中文清晰、高 DPI 屏可读 | 默认 ImGui 字体（中文差/锯齿） |
| thorvg **暂不入 MVP** | 百万要素主层 VBO 已足够；点缀层后续可选 | 首版即引入 thorvg（增加复杂度/依赖） |
