# 属性表设计（peekGIS）

> 版本：v0.1（草案）
> 承接《需求分析》《总体设计》《详细设计》。
> 本文聚焦**底部属性表面板**的功能与**属性读取的可靠性设计**——重点是「怎么读属性才靠谱」。

---

## 1. 目标与交互

新增一个**底部停靠面板「属性表」**：

- 分页显示（**每页 20 行**，可翻页/跳页），缓存 3~5 页。
- 面板标题栏：图层名、**编码下拉（实时切换）**、翻页控件、总页数/总行数。
- **双击某行**：视图**仅居中平移**到该要素（不缩放）并**高亮**该要素。
- **图层右键菜单 →「打开属性表」**：把底部面板绑定到该图层；绑定其它图层时切换内容。
- 关闭面板 / 换图层时释放缓存。

支持的编码（下拉可切换，**固定所选**）：**UTF-8 / GBK / Big5 / CP1252 / UTF-16(LE)**。
> 面向 shp 的 `.dbf`；对内部本就 UTF-8 的格式（gpkg 等）不强制转码。

> **两处都要编码下拉**：
> 1. **底部属性表面板**（本设计主体）。
> 2. **右栏属性查询面板**（双击地图识别，`IdentifyHit.attrs`）——同一个「固定编码解释器」交互（见 §8）。

### 1.1 编码语义（重要，明确用户意图）

面板上的**编码下拉框**是一个「**固定解释器**」：不管源文件 `.cpg`/LDID 标记的是什么编码，
用户在属性表里选 **GBK**，那么该面板所有字符串属性就**一律按 GBK 解码显示**；选 UTF-8 就按 UTF-8。

- 典型场景：某 shp 的 `.dbf` 属性实际是 **GBK**，但 `.cpg` 却写着 `UTF-8`（瞎填）。用户在面板
  下拉里选 **GBK**，属性立刻正确显示，无需改文件、无需重读。
- **切换编码绝不重读文件**：切换只影响「如何解释已读到的字节」。
- 因此读取阶段必须拿到**原始字节**（见 §2.4），编码作为显示期的解释参数（见 §2.5）。

## 2. 读取可靠性设计（核心）

要求：**任何 GDAL/OGR 能开的矢量格式都能打开属性表**，且分页/跳页要快、编码可实时切换。逐项给出「靠谱」的做法。

### 2.1 总数与字段定义（一次性，打开时取）

| 信息 | 接口 | 说明 |
|------|------|------|
| 要素总数 | `OGR_L_GetFeatureCount(lyr, FALSE)` | shp：直接读 `.dbf` 记录数（毫秒）；gpkg：SQL count。够用于分页 |
| 字段数量 | `OGR_F_GetFieldCount(f)` | 取任一要素 |
| 字段名/类型/宽度 | `OGR_F_GetFieldDefnRef(f,k)` → `GetNameRef/GetType/GetWidth/GetPrecision` | 建表头 |

> 字段名本身也可能是非 UTF-8 字节（DBF）。字段名同样按所选编码转码显示（与值同策略）。

### 2.2 分页/跳页（跨格式可靠）

**逐页从文件读取，一次只拉当前页 20 行 + 前后若干页缓存。** 关键：怎么定位到第 N 页起点。

- **优先 FID 随机访问**：`OGR_L_GetFeature(lyr, fid)`。
  - shapefile：**FID=记录号（0 基）**，`GetFeature(offset)` 直达第 offset 条，O(1)。
  - gpkg：FID=主键（默认 0 基），`GetFeature` 按主键直达，O(1)。
  - 派生条件：`OGR_L_TestCapability(lyr, OLCRandomRead)` 为真即用。
- **回退顺序跳过**：`ResetReading` 后 `GetNextFeature` 跳过前 `offset` 条再读 20 条。
  - 对无随机读能力的驱动（部分文本/GML 等）：O(offset)，百万级到末页可能慢，但能打开。面板上对这类驱动提示「跳页较慢」。

> ⚠️ **FID 空洞风险**（重点）：gpkg 删除记录后 FID 不连续；shp 几乎连续但有删除标记（写入标记 `*` 的记录生效后也不连续）。因此**表内明确显示 FID 列**，且**几何/定位以 FID 为键**，避免“行号=第 N 个”错位。读取时对每条记录同时返回 `OGR_F_GetFID()`。

### 2.3 单元格取值：区分「字符串」与「非字符串」

- **非字符串字段**（Int/Int64/Real/Date/DateTime/Time）：用 GDAL 原生对齐
  `OGR_F_GetFieldAsInteger64/GetFieldAsDouble/GetFieldAsDateTime` 格式化（与现有
  `gdal_datasource.cpp::appendFieldAttr` 一致），**不做编码转换**。
- **字符串字段（DBF）**：读到**原始字节**，暂存字节；显示时才按所选编码转成 UTF-8。

### 2.4 读原始字节（编码可实时切换的关键）

对 shp 的 `.dbf`：GDAL 默认会按 `.cpg`/LDID 自动转码。我们要“未解码的原始字节”：

```
打开时（保持本次会话一致）:
  CPLSetConfigOption("SHAPE_ENCODING", "");   // 空串 = 不做任何 recoding, 返回原始字节
  // (对已打开的 keeper dataset，读字符串前设置；或对属性表专用 dataset 设置)
```

- GDAL 文档明确：`SHAPE_ENCODING` 置**空串 `""`** 即「不 recode，返回原始字节」。
- 之后 `OGR_F_GetFieldAsString(f,k)` 拿到的是 **DBF 里的原始字节**（按字段定长截断/去空格后），存入单元格缓存。

### 2.5 实时切换编码（不重开文件、不重读）

- 每个字符串单元格缓存的是**原始字节**（`std::vector<byte>`），每次切换编码只对**当前已缓存页**重转一次，瞬时完成，**不重开文件、不重读**。
- 面板下拉框选的是「固定解释编码」（§1.1）：切换 = 把已读到的原始字节按新编码重新转成 UTF-8 显示。
- 转码表（Windows 用 Codepage，跨平台回退 `CPLRecode`/iconv）：

| 面板选项 | Windows CodePage | 说明 |
|----------|------------------|------|
| UTF-8 | 65001 | 原样/校验 |
| GBK | 936 | 简体中文 |
| Big5 | 950 | 繁体中文 |
| CP1252 | 1252 | 西欧/拉丁 |
| UTF-16(LE) | 1200 | UTF-16 小端 |
- 转码实现：`MultiByteToWideChar(cp, ..., raw, rawLen, ...)` → `WideCharToMultiByte(CP_UTF8, ...)`。
- 无效字节/无法映射：替换为 `U+FFFD`（`?`），不崩溃。

### 2.6 非 shp 格式（gpkg 等）

- gpkg（SQLite）字段值**存储即 UTF-8**，`OGR_F_GetFieldAsString` 已返回 UTF-8，**无需转码**。
- 对这类驱动：编码下拉**禁用**（或仅显示且等价 UTF-8），避免误导。判定：`OGR_Dr_GetName(driver) != "ESRI Shapefile"` 时按 UTF-8 直通。

### 2.7 几何（双击定位/高亮用）

- 每行读取时**顺带取几何**：`OGR_F_GetGeometryRef(f)` + 现有 `addFilledGeometry`/`addGeometry`
  抽取 `outline/points/fillTris`（**源 CRS**），仅对当前缓存页保留。
- 双击行 → 用该行几何的包围盒中心作为目标点：
  - **只平移不缩放**：`scene.pan` 使该点居中（改变 `centerX/centerY` 使屏幕中心对到目标）。
  - **高亮**：把该行几何加入一个「表格高亮」集合，渲染复用 `drawIdentifyHighlight` 同款黄色高亮叠加
    （显示 CRS 由 `toDisplayCrs` 重投影）。
- 几何与属性页缓存一致：翻页后高亮集合清空。

## 3. 模块与数据结构

新增 `src/data/attr_table.h/.cpp`（读取）+ `src/app`（UI）+ `src/main.cpp`（后台线程）三块。

### 3.1 数据结构 (attr_table.h)

```cpp
struct AttrCell {                       // 一个单元格
    bool isRawBytesToDecode = false;    // true=字符串原始字节(待转码), false=已格式化文本
    std::vector<unsigned char> raw;     // 原始字节(字符串)
    std::string text;                   // 显示用 UTF-8(已按当前编码)
};
struct AttrRow {
    long long fid = 0;
    std::vector<AttrCell> cells;
    int geomKind = 0;
    std::vector<float> outline, points, fillTris;  // 源 CRS
};
struct AttrPage {
    int page = 0;
    std::vector<AttrRow> rows;          // 0..rowsPerPage
};

// 后台读取结果 → 主线程(锁保护)
struct AttrTableState {
    std::string path;                   // 当前绑定文件
    int layerIdx = 0;
    std::string layerName;
    std::vector<std::string> fieldNames; // UTF-8, 按当前编码
    long long total = 0;
    int rowsPerPage = 20;
    int cachePages = 4;                 // 缓存 3~5 页
    std::vector<AttrPage> pages;        // 最近 N 页缓存
    int currentPage = 0;
    int encoding = 0;                   // 0=UTF8 1=GBK 2=Big5 3=CP1252 4=U16LE
    bool fileChanged = true;            // 需要重读(打开/换层/编码变更后重转不重读)
    bool loading = false;               // 后台读取中
};
```

### 3.2 读取函数 (attr_table.cpp)

```cpp
// 打开属性表: 取总数/字段定义, 后台线程拉第 cur 页
bool openAttrTable(const std::string& path, int layerIdx, AttrTableState& st,
                   int rowsPerPage, int cachePages, int encoding);

// 后台线程: 拉取某一页(优先 FID 直达, 否则顺序跳过)
void fetchAttrPage(const std::string& path, int layerIdx, int page,
                   int rowsPerPage, int encoding, AttrTableState& st /*锁保护*/);

// 编码切换: 不重读, 只把已缓存页的 raw 重转为 UTF-8
void reencodePages(AttrTableState& st, int newEncoding);
```

### 3.3 UI（app/ui.cpp）

- 新底部窗口 `"属性表"`（加入 dock 布局 `buildDockLayout`，如底部分区增高）。
- 面板结构：`图层名 | 编码下拉 | 上一页 | 页码/总页 | 下一页 | 跳页 | 行数 | 总行数`。
  - **编码下拉**：`ImGui::Combo("编码", &encoding, {"UTF-8","GBK","Big5","CP1252","UTF-16(LE)})`。
    用户切换后**不重读文件**，只把已缓存页的原始字节按新编码重转显示（§2.5）。选中编码即为该面板的固定解释编码。
- 表格（`ImGui::BeginTable` 列 = 字段）：首列 **FID**，其后各字段列。
- **行双击**：`ImGuiTableFlags_RowBg` + `IsItemHovered && IsMouseDoubleClicked` → 置 `locateRequested`（携带 fid/几何）。
- 图层右键（ui.cpp `layerctx` 弹窗）新增「打开属性表」。

### 3.4 主线程 / 并发（main.cpp）

- 与 `identifyFeatures` 相同的**后台线程 + mutex 提交**模式，避免卡主线程。
- 源文件读取复用 `gdalKeeperEnsure` 的 per-path dataset + 锁，与 identify 互斥不冲突。
- 已缓存页数超过 `cachePages` 时淘汰最久未用页。
- UI 请求：打开/翻页（进 `pending` 队列）→ 后台逐页拉取 → 主线程每帧取回置 `st.pages`。

## 4. 权衡与风险

| 项 | 权衡/风险 | 对策 |
|----|-----------|------|
| 顺序跳页 O(offset) | 非随机读驱动到末页慢 | 优先 FID 直达；标注「跳页较慢」 |
| FID 空洞 | 行序≠FID，定位错位 | 表内显 FID 列；几何/定位以 FID 为键 |
| 编码切换性能 | 每次切换重转整层会卡 | 只重转**已缓存页**，瞬时完成；不重读、不重开文件 |
| 大文件内存 | 全量载入会爆内存 | 只缓存 3~5 页 + 每页的几何 |
| DBF 字段非 UTF-8 | 表头/值乱码 | 字段名/字符串值统一按所选编码转码（见 §1.1 固定编码语义） |

## 6. 已确认的决策

- **编码语义 = 固定解释器**：面板下拉选中的编码即为该面板对所有字符串属性的固定解释编码，
  与源文件 `.cpg`/LDID 无关；切换编码**不重读文件**（§1.1）。
- **切换编码实现 = 原始字节 + 内存重转**：读取阶段保存原始字节，切换时对已缓存页重转显示（§2.4/§2.5）。

## 7. 属性查询面板的编码下拉（右栏 Identify）

现状：双击地图识别的结果在**右栏 Attributes**，`IdentifyHit.attrs` 是字符串对，读取时由
`gdal_datasource.cpp::appendFieldAttr` 用 `OGR_F_GetFieldAsString` 拿到 GDAL **已按 cpg/LDID
自动解码**的 UTF-8。

要支持「固定编码 + 不重读」，与属性表一样的思路：

- **识别阶段返回原始字节**：识别读取时也设 `SHAPE_ENCODING=""`，`IdentifyHit.attrs`
  增加一个「原始字节」缓存（各字段值保留原始字节），几何/数字仍照常。
- **右栏加编码下拉**（顶部 `ImGui::Combo("编码", ...)`，与属性表同一套选项）：切换时
  **只把当前识别结果**的原始字节按新编码重转显示，**不重新查询、不重读文件**。
- 该下拉同样为「固定解释器」：用户选什么，右栏所有字符串属性就按什么解码。
- 高亮叠绘（过程）不变。

> 仅在 shp（DBF）下生效；gpkg 等 UTF-8 直通格式该下拉禁用。

数据流：
```
双击 → identifyFeatures(以 SHAPE_ENCODING="" 读, 缓存 raw)
     → 右栏当前编码 → 转码显示
     → 用户切编码 → 仅重转当前 IdentifyHit.attrs 的 raw → 刷新显示
```
