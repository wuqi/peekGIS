## 1. 视图与坐标系

### 1.1 显示 CRS（display CRS）
- MapScene 持有 `displayEpsg`。
- **默认规则**：首次打开用**数据自身 CRS**；若数据无 CRS，则回退 **EPSG:4326**（见 §3）。
- 所有图层在渲染前投影到 `displayEpsg`，保证对齐。
- 用户可在 UI 中**切换显示 CRS**（见 §3.3 / §5.5），切换后全局重投影。

### 1.2 视图状态（ViewState）
```cpp
struct ViewState {
    double centerX, centerY;   // 显示CRS下的中心坐标
    double scale;              // 每像素对应的世界单位（或 zoom 级别）
    double rotation = 0.0;     // 可选
    int viewportW, viewportH;  // 地图Dock像素尺寸
};
```

### 1.3 屏幕 ↔ 世界互转（显示 CRS）
- 世界→屏幕（绘制用）：
  ```
  screenX = (worldX - centerX) / scale + viewportW/2
  screenY = viewportH/2 - (worldY - centerY) / scale   // 屏幕y向下
  ```
- 屏幕→世界（鼠标拾取/状态栏）：
  ```
  worldX = (screenX - viewportW/2) * scale + centerX
  worldY = centerY - (screenY - viewportH/2) * scale
  ```
- 实际绘制时，上述变换用 `glm::mat4` 作为 MVP 传入顶点着色器，CPU 端不逐顶点算。

### 1.4 顶点着色器（主层）
```glsl
#version 330 core
layout(location=0) in vec2 aPos;     // 显示CRS坐标
uniform mat4 uMVP;                    // 视图变换
void main(){ gl_Position = uMVP * vec4(aPos, 0.0, 1.0); }
```
- `uMVP` = ortho(0..W, 0..H) * viewTranslateScale。
- 线宽：`glLineWidth`（基础）；需要粗线再在几何着色器/预处理扩成 quad。
- 颜色/分类：可由 `aColor` 属性或 `uClassColor` uniform 提供（按属性着色）。

## 2. VBO 几何缓存（.geomcache）

### 2.1 sourceId 与签名
```cpp
// sourceId = sha1(绝对路径 + '|' + mtime + '|' + size)
// 文件命名：<cacheDir>/<sourceId>.geomcache
struct CacheSignature {
    int64_t mtime;
    int64_t size;
};
// 打开时：计算当前源 mtime/size；与缓存header比对，不一致则重建
```

### 2.2 二进制布局（小端）
```
[Header 固定 64B]
  magic        : 4B   "PGGC"
  version      : u32
  sourceEpsg   : i32   // 源CRS（缓存存源坐标！）
  displayEpsg  : i32   // 记录构建时的显示CRS（仅参考）
  geomKind     : u8    // 0=线(LINES) 1=面(填充索引) 2=混合
  hasClass     : u8    // 是否带分类属性
  _pad        : u16
  vertexCount  : u32
  indexCount   : u32
  bboxSrc      : 4×f64 // 源CRS包围盒
  srcMtime     : i64
  srcSize      : i64   // ← 签名，用于失效
  _reserved    : 8B

[Vertices]  vertexCount × (x f32, y f32)   // 源CRS坐标
[Class]     vertexCount × u8               // 可选：分类id
[Indices]   indexCount  × u32              // 面填充索引(线可无)
```
- 坐标存**源 CRS f32**：重开只上传，投影在加载时一次性做（PROJ 单遍，极快）。
- 线以 `LINES` 存储（每线段两顶点，可重复顶点）可免去索引，最简单；面用索引三角化。

### 2.3 读写流程
```cpp
// 命中缓存
if (cacheExists(sourceId) && sigMatch()) {
    mmap(file);
    glBufferData(GL_ARRAY_BUFFER, fileSize - header, ptr); // 直接上传
    projectFromSourceToDisplay(); // 源坐标→显示CRS（PROJ单遍）
}
// 未命中
else {
    OGR read all features -> flatten to sourceCRS vertices
    write .geomcache (source coords + sig)
    upload + project
}
```
- mmap 零拷贝：`glBufferData` 直接吃映射指针，不进用户态内存。
- 体积：100 万线 × 均 5 顶点 ≈ 5M×8B = 40MB；面多些也仅百 MB 级。

## 3. 动态重投影（核心设计）

### 3.1 设计要点
- **缓存存源 CRS 坐标** → 重投影不需要重读 OGR，只需对缓存顶点做 PROJ 变换。
- 加载与切 CRS 都是“对 N 个顶点做一次 PROJ 变换”，成本极低（1M 点几十~几百 ms）。

### 3.2 模块接口
```cpp
class Reprojector {
    // 源EPSG -> 显示EPSG 的变换器（GDAL OGRCoordinateTransformation）
    std::vector<glm::vec2> project(const std::vector<float>& srcXY,
                                   int srcEpsg, int dstEpsg);
    glm::vec2 inverse(double x, double y); // 显示->源（单点，状态栏用）
};
```
### 3.3 流程
```
打开/加载:
  srcXY(源CRS) --Reprojector-> dstXY(显示CRS) --upload--> VBO

切换显示CRS(dropdown):
  newDst = 选中的EPSG
  for each layer:
     srcXY(缓存) --Reprojector(srcEpsg,newDst)--> 新 VBO
  所有图层自然对齐到 newDst
```
- 多源对齐：各图层 `srcEpsg` 不同，但都投到同一 `displayEpsg`。
- 切 CRS 是显式操作（按钮/下拉），非每帧；故无持续开销。

## 4. 渲染管线

### 4.1 地图渲染到 FBO
```
1. 绑定离屏 FBO（尺寸=地图Dock尺寸，resize时重建）
2. glViewport(0,0,W,H); 清屏
3. 绘主层VBO（线/面，应用uMVP）
4. （可选）绘 thorvg 点缀层到叠加纹理
5. 解绑FBO
6. ImGui::Image(fboTexture, ImVec2(W,H)) 贴到地图Dock
```
- 优点：地图成为普通 ImGui 图像，停靠/拖拽/缩放自适应，与 docking 布局解耦。
- 缺点：多一次 FBO 拷贝（可接受，简单稳定）。

### 4.2 绘制顺序
栅格底图（若有） → 矢量面填充 → 矢量线 → 选中/标注（thorvg） → UI 覆盖。

### 4.3 坐标拾取（状态栏）
```
on mouse move in MapView:
  screen = (mx, my) 相对地图Dock
  world = screenToWorld(screen, viewState)   // 显示CRS
  src   = reprojector.inverse(world)          // 源CRS（可选）
  statusBar.show(world, src)
```

## 5. ImGui 布局（docking）

### 5.1 初始化
```cpp
ImGuiIO& io = ImGui::GetIO();
io.ConfigFlags |= ImGuiConfigFlags_DockingEnable;
io.ConfigFlags |= ImGuiConfigFlags_NavEnableKeyboard;
// 可选：ViewportsEnable（多窗口，先不做）
```
### 5.2 主循环布局
```cpp
ImGui::DockSpaceOverViewport(ImGui::GetMainViewport());
// 左 Dock
if (ImGui::Begin("Layers")) { renderLayerPanel(); }
ImGui::End();
// 中 Dock（地图）
if (ImGui::Begin("Map")) {
    ImVec2 sz = ImGui::GetContentRegionAvail();
    ImGui::Image((ImTextureID)fboTex, sz);
    captureMapInput(); // 平移/缩放/鼠标坐标
}
ImGui::End();
// 底 Dock（状态栏）
if (ImGui::Begin("StatusBar")) { renderStatusBar(); }
ImGui::End();
```
### 5.3 左栏（LayerPanel）字段
- 图层名、可见性 checkbox、上移/下移按钮、源 CRS、要素数、（可选）颜色块/分类开关。
- 数据源：遍历 `MapScene.layers`。

### 5.4 状态栏（StatusBar）
- 显示：鼠标处 显示CRS 坐标（如 `lon, lat`）；可并列源 CRS 坐标；当前缩放；活动图层数。

## 6. 栅格 mmap 分块

### 6.1 流程
```
GDALOpen(卫片)
 - 读 RPC metadata domain（若存在）→ 存 Layer.rpc
 - 建立文件 mmap
Worker线程:
 - 由当前视图bbox计算所需区块
 - 从 mmap 区域解码该块 → RGBA 缓冲 → 上传子纹理
主线程合成: 贴栅格纹理（位于矢量下或上，按图层顺序）
```
### 6.2 RPC
- 读取 `RPC` 元数据（GDAL `GetMetadata("RPC")`），保存 90 参数。
- 展示：状态栏/图层信息显示“含RPC”。
- 定位：可用 `GDALCreateRPCTransformer` 计算影像角点地理坐标（精确贴图为后续增强）。

## 7. 多线程（Worker 池）

```cpp
class WorkerPool {
    std::vector<std::jthread> threads;
    moodycamel::ConcurrentQueue<Task> q; // 或自研无锁队列
public:
    void enqueue(Task t);
};
// Task: BuildVBOTask(layer) / DecodeRasterTask(tile)
```
- 首打开：主线程先显示范围框/空地图，Worker 后台建 VBO/写缓存，完成即刷新。
- 避免主线程阻塞，保证 UI 响应。

## 8. thorvg 点缀层（可选，非百万要素）

- 用途：选中要素高亮、标注文字、图例、少量（<几千）样式化矢量。
- 用法：从 OGR 取子集 → 建 thorvg `Scene`/`Picture` → 渲到叠加纹理或直接 `SwCanvas`。
- **不用于**百万主层（见总体设计 §7）。

## 9. xmake 写法（草案）

```lua
-- xmake.lua
add_rules("mode.debug", "mode.release")

-- 依赖（包名以 xrepo 实际为准，搭建时核对）
add_requires("glfw")
add_requires("glad")          -- GL 3.3 core loader
add_requires("imgui")        -- 需 docking 分支；若 xrepo 不含 docking，
                             -- 改为 vendor/imgui(docking) 子模块
add_requires("gdal")
add_requires("glm")
add_requires("spdlog")
add_requires("sqlite3")       -- 缓存清单(可选)
-- add_requires("zstd")       -- 缓存压缩(可选)
-- add_requires("thorvg")     -- 点缀层(可选，MVP后可加)

target("peekgis")
    set_kind("binary")
    set_languages("c++20")
    add_files("src/**.cpp")
    add_includedirs("src")
    add_packages("glfw", "glad", "imgui", "gdal", "glm", "spdlog", "sqlite3")
    -- if has_config("thorvg") then add_packages("thorvg") end

-- 本机构建
--   Win64 : xmake f -p windows -a x64 && xmake
--   Linux: xmake f -p linux   -a x64 && xmake
--   麒麟  : xmake (原生 aarch64)
-- 交叉到麒麟(在x64主机):
--   xmake f -p linux -a arm64 --toolchain=cross --sdk=/opt/aarch64-linux-gnu && xmake
```

> 注意：`imgui` 的 docking 能力需确认 xrepo 包是否含 docking 分支；若不含，
> 采用 vendor 子模块方式引入 `imgui` docking 分支（更稳妥）。
